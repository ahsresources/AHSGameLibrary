# Icons needed in the assets/ folder

Save each picture as **.png** (square works best, about 300 x 300 px, transparent background).
To use another format (svg, jpg, webp), change `ICON_EXT` at the top of `data.js`.

If a file is missing the app shows an emoji instead, so you can add icons a few at a time.

Skin tones and the 12 colours use colour circles, so they need no icon files.
