Pole display

Welcome to Pole display

Scan a barcode and your customer instantly sees the item’s name, price and picture on a glowing display screen, like the ones at a shop counter.

1. Scan

Use a USB barcode scanner, or the camera on your phone, tablet or laptop.

2. Show

The Display tab shows the name and price. Choose to show just the screen, or the screen with a picture. Use Full screen for the customer’s side.

3. Manage

The Products tab is your list. Add items, change prices, swap pictures and keep a backup.

Frequently asked questions

How do I connect and use a USB barcode scanner?
  1. Plug the scanner into a USB port. Most scanners work like a keyboard, so there is nothing to install. Bluetooth scanners need to be paired first, the same way as a Bluetooth keyboard.
  2. Open this page and select the Display tab.
  3. Scan an item. You will hear a beep and see its name and price. You do not need to click anywhere first.
  4. The price stays on screen until the next scan. Select Reset to welcome (or press the Delete key) to go back to the welcome message.

Nothing happens when I scan?

  • Make sure this page is the window in front. The scanner only types into the window you are using.
  • Test the scanner in another program, such as Notepad. It should type the numbers and then start a new line. If it types the numbers but does not start a new line, the scanner needs its “Enter” setting switched on. Your scanner’s manual has a setup barcode for this.
  • If the item says “not found”, it has not been added to your list yet. See the questions below.
Using a second screen for customers? Open this page in two browser tabs. Scan in the first tab and put the second tab on the customer’s screen. Both tabs show the same item.
How do I create or use barcodes?

Items that already have a barcode (most things from a shop or supplier): you do not need to create anything. Just scan the printed barcode when you add the item. The app remembers that number.

Items with no barcode (homemade or loose items):

  1. Choose a short number that no other item uses, for example 1001, 1002, 1003.
  2. Add the item with that number as its barcode (see the next question).
  3. Make a printable label. Search online for a free “barcode generator”, choose Code 128, type your number and print it. Stick the label on the item.
  4. Scan the label to check it works.
Every item needs its own number. Two items with the same barcode cannot be told apart. You can also type any number into the box at the top of the page and press Enter, which is handy for testing.
How do I add items to the list?
  1. Select the Products tab.
  2. Select Add product. Or, even quicker, scan the item’s barcode while you are on this tab and the form opens with the barcode filled in.
  3. Type the name and the price.
  4. Add a picture if you like. Choose a photo from your device, drag one in, or paste one. It is resized for you.
  5. Select Save product.

To change an item later, select it in the list. You can edit anything or delete it there.

Lots of items? Select Backup and import and paste a list with one item per line, in this order: barcode, name, price. For example: 9300000000017,French Barbie,10.50. You can add pictures afterwards.

Your list is saved in this browser on this device only. Use Backup and import then Export all now and then, and keep the copied text somewhere safe.
