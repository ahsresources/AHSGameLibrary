# Money Skills

Static website, no build step. Open `index.html`, or upload the whole folder to any web host.

## Add your files to the `assets/` folder
Purchasing steps (9 steps):
- Videos: 1.mp4, 2.mp4, 3.mp4, 6.mp4, 7.mp4, 8.mp4, 9.mp4
- Pictures: 4.jpg, 5.jpg  (steps 4 and 5 show a picture instead of a video)

Game pictures (shown on the cards; icons are used until a picture is added):
fillthewallet.png, scoopshop.png, fishshop.png, supermarketrun.png,
shoppinglistgame.png, coincombination.png, moneycalculator.png,
addupmoney.png, cashiersimulator.png

Videos play from a web host or local server; some browsers restrict file:// pages.

## Structure
index.html, purchasing.html, games.html, css/style.css, js/purchasing.js
(assets/img/ holds the step thumbnails, which are part of the site)
